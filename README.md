# Вершина — Северодвинск

Городской сайт https://vershina029.ru/. Хостинг — Yandex Object Storage, www перенаправляется на основной HTTPS.

## Разработка

Node 24, pnpm 11.7.0. `pnpm install --frozen-lockfile`, `pnpm run build`.

Обычные утверждённые ставки: 150/230/370–450/280/410–500 ₽/м². Минимум выезда 6 000 ₽ на общую сумму. Контакты проекта сохранены. Hero — AI-иллюстрация с видом на берег Ягры; примеры до/после — иллюстрации, не местные заказы.

GitHub Actions публикует только dist в бакет vershina029.ru с отдельным deployer. Секреты хранятся только в Actions Secrets. Рекламные URL с UTM ведите сразу на основной домен: www-редирект Object Storage теряет query string.
