# Вершина — Северодвинск

Городской сайт https://vershina029.ru/. Хостинг — Yandex Object Storage, www перенаправляется на основной HTTPS.

## Разработка

Node 24, pnpm 11.7.0. `pnpm install --frozen-lockfile`, `pnpm run build`.

Обычные утверждённые ставки: 150/230/370–450/280/410–500 ₽/м². Минимум выезда 6 000 ₽ на общую сумму. Контакты проекта сохранены. Первый экран повторяет схему vershina29.ru: белый фон, текст слева, отдельное фото справа и карточка «47 пунктов»; на телефоне текст расположен перед фото. Hero обновлён 16.11.2026 по референсу владельца: крупный уютный диван, чистый стол и гостиная после уборки; Дом корабела за окном — второстепенный фон. Файл hero-severodvinsk-clean-apartment.webp, 1120×1400, с центральным кадрированием без потери композиции. Это сгенерированная иллюстрация, не фактическая фотография конкретной квартиры. OG сохранён отдельно. Примеры до/после — иллюстрации, не местные заказы.

GitHub Actions публикует только dist в бакет vershina029.ru с отдельным deployer. Секреты хранятся только в Actions Secrets. Рекламные URL с UTM ведите сразу на основной домен: www-редирект Object Storage теряет query string.
